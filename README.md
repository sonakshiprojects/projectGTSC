Supply Chain Analytics & Inventory Optimization

An end-to-end supply chain analytics project focused on inventory optimization, demand analysis, stockout risk, and supplier performance using Python, MySQL, and MS Excel.

Key Highlights
Processed 50K+ transactions using Python and MySQL to identify inventory movement, demand patterns, supplier performance, and operational trends.
Performed inventory classification, demand analysis, and safety stock analysis using Python and MS Excel to identify stockout risks and support inventory planning.
Applied quantitative analysis and KPI evaluation to assess inventory and supplier performance and generate actionable recommendations for improving operational efficiency.
Tools & Technologies
Python: Pandas, NumPy, Matplotlib, Seaborn
Database: MySQL
Analytics: Inventory Classification, Demand Analysis, Safety Stock Analysis, KPI Analysis
Excel: Data Analysis, Pivot Tables, KPI Reporting
Business Outcomes

The analysis provides insights into inventory movement, stockout risk, demand patterns, and supplier performance, supporting more informed inventory planning and operational decision-making.
